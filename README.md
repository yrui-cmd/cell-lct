# 描绘心声

**Science Speaks in Vectors**

让每一个科研想法，都有被看见的形状。

描绘心声是一款面向 Adobe Illustrator 的科研矢量绘图辅助工具。上传参考图片或描述研究内容，即可在当前画板中生成、重绘和继续添加可编辑科研矢量图，同时保留已有内容。

> 本项目为独立第三方工具，与 Adobe 无隶属、赞助或官方认可关系。

## 第一次使用：只需 3 步

### 第 1 步：安装插件

将下面这段话发送给 Codex：

```text
请安装“描绘心声”项目。把仓库根目录注册为 Codex Marketplace，
然后安装 miaohui-xinsheng@miaohui-xinsheng-tools。
安装完成后提醒我重新启动 Codex 并新建任务。
```

### 第 2 步：打开 Illustrator

1. 打开 Adobe Illustrator 2026。
2. 打开准备绘制的 AI 文档。
3. 保持该文档处于打开状态。

Illustrator 由用户自行打开和管理，描绘心声只负责在当前画板中绘制。

### 第 3 步：告诉 Codex 画什么

```text
使用描绘心声，在当前画板右上角画一个小兔子。
```

也可以上传参考图片后发送：

```text
使用描绘心声，参考这张图片，在当前画板中上方重绘。
保留全部已有内容，不要覆盖文字。
```

## 统一科研绘图提示词

```text
使用描绘心声。

你是一名经验丰富的科研绘图设计师。请根据我提供的研究内容，绘制符合顶级期刊标准的 BioRender 风格科研配图，并严格遵守以下规范：

1. 采用清晰的科研矢量插画风格，避免照片感和写实感。
2. 使用纯白色背景和扁平化 2D 设计，禁止任何 3D 渲染。
3. 禁止使用光影渐变、镜面反射、复杂纹理、电影级光效、立体阴影及其他写实效果。
4. 整体保持简约、整洁，所有线条干净流畅，颜色使用纯色色块平涂。
5. 构图、配色、比例、留白和信息层级应符合行业顶级期刊的科研绘图标准。
6. 全图中的同类事物必须保持绝对一致，包括颜色、形状、大小、比例、线宽、结构和内部细节。
7. 所有重复小元素必须分别绘制为彼此独立的单个图形，不得相互连接、融合、共用外轮廓或连成一个整体。

绘图内容：【填写研究内容或对象】
绘制位置：【填写画板位置】
绘制尺寸：【填写尺寸或画板占比】
避让区域：【填写不能覆盖的文字或图形】
其他要求：【填写配色、标签或结构要求】

保留当前画板中的全部已有内容，不得删除、隐藏、替换或覆盖。
```

## 使用环境

- Windows
- Codex Desktop
- Adobe Illustrator 2026

## 注意事项

- 开始前先打开目标 Illustrator 文档。
- 绘制过程中不要关闭该文档。
- 不需要让 Codex 打开或调整 Illustrator 窗口。
- 明确说明绘制位置、尺寸和避让区域。
- 重要项目建议提前保存备份。
- 不要上传患者隐私、密码或其他敏感内容。
